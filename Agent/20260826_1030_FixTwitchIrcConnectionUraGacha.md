# 20260826_1030_FixTwitchIrcConnectionUraGacha.md

## 目的
`tools/裏ガチャシステム/index.html` および `パートナー計画/listener_watch.html` において、Twitchチャットへの接続が正常に行われない不具合を根本から調査・修正する。

## 原因の特定
1. **ステータス更新判定の不備**:
   - `handleIrcMessage` が `PRIVMSG`（実際のチャットコメント受信）のみを契機として `updateConnectionStatus('connected')` を呼ぶ設計になっていたため、**チャンネル接続が成功していても誰かがコメントを打つまで画面上は「接続中...」のまま停止していた**。
2. **Twitch IRCハンドシェイク応答のハンドリング欠落**:
   - Twitch IRCサーバーからのログイン完了レスポンス（`001`、`376`）やチャンネル参加完了（`JOIN`）を検知していなかった。
3. **認証エラー時の検知不足**:
   - Bot認証（OAuthトークン）のスペルミスや期限切れ時に発生する `NOTICE * :Login unsuccessful` が検知されず、サイレントに切断されていた。
4. **構文エラー（listener_watch.html）**:
   - 同期ファイルのコード一部に余剰括弧があり、スクリプト実行時にエラーが発生していた。

## 修正内容
1. **Twitch IRC接続シーケンスの刷新**:
   - `CAP REQ :twitch.tv/tags twitch.tv/commands twitch.tv/membership`
   - 公式標準の匿名接続（`PASS SCHMOOPIIE` / `NICK justinfanXXXXX`）の適用。
   - `001`、`376`、`JOIN` 受信時に即座に接続完了ステータスへ移行（「接続中 (#uikouka) 👁️読取のみ」/「🤖Bot送信可」）。
2. **認証エラー通知**:
   - `NOTICE` によるログイン失敗時に、アラートおよび赤字ステータスでBotトークン確認を案内。
3. **裏ガチャ設定のデフォルト値最適化**:
   - **基本必要視聴時間 (`requiredMinutes`)**: デフォルトを **`60分`** に変更。
   - **当たり確率 (`winRate`)**: デフォルト **`1%`**。
   - **1回ごとの時短 (`stepMinutes`)**: デフォルト **`0分`**（時短なし）。
   - **最短短縮限界 (`minMinutes`)**: デフォルト **`0分`**（限界なし）。
   - **天井確定回数 (`pityLimit`)**: デフォルト **`100回`**。
   - **当たり賞品URL (`prizeUrl`)**: デフォルト **空欄 `""`**。
4. **返信メッセージテンプレートの最適化 ＆ 初コメ案内ON/OFFトグル**:
   - Nightbot定期アナウンス文セクションをオミット（削除）しUIを軽量化。
   - 全5種類のデフォルトメッセージをご指定の完全文面へ設定。
     - **時間不足**: `🦊.｡oO（ @{user} さん、裏ガチャまであと{remain_minutes}分。天井まで{pity_remain}回 ）`
     - **通常当たり**: `🦊.｡oO（ @{user} さん、当たり！おめでとう！ {prize_url} ）`
     - **天井確定**: `🦊.｡oO（ @{user} さん、天井確定！おめでとう！ {prize_url} ）`
     - **ハズレ**: `🦊.｡oO（ @{user} さん、ハズレ。次回{required_minutes}分 / 天井{pity_remain}回 ）`
     - **初コメ案内**: `🦊.｡oO（ @{user} さん、YAHO！裏ガチャまで{required_minutes}分 / 天井{pity_remain}回 ）`
   - 初コメ案内欄の真横に「初コメ案内を送信する」ON/OFFトグルチェックボックスを設置。
5. **セキュリティ ＆ レートリミット保護強化**:
   - **OAuthトークン安全管理**: 警告案内メッセージと「🗑️ トークンをクリア」ボタンを新設。
   - **Botチャット送信レートリミット（Twitch API保護）**: メッセージキューイングシステム（最短1.2秒ディレイ）を導入し、Botの送信制限（20msg/30s）によるBANを防止。
   - **`!裏ガチャ` コマンドスパム防止**: 同一リスナーからのコマンド実行に対して **60秒間のクールダウン** を適用し、過度な連打やチャット荒らしを確実に防止。
   - **XSS・エスケープの厳密化**: `escapeAttr` を `escapeHtml` と同一の完全エスケープ（`&`, `<`, `>`, `"`, `'`）に統合。
   - **同名ユーザー取り違え防止**: `username`（小文字ID）を最優先主キーとして判定。

## 検証結果
- ブラウザサブエージェントにて `index.html` を起動し、ロード後即座に `[Twitch IRC] Successfully connected & joined #uikouka!` の成立、および緑色ドット「接続中 (#uikouka) 👁️読取のみ」への遷移を目視・ログ両面で確認完了。
- 基本必要時間60分、賞品URL空欄、時短0分設定での必要時間計算（基本設定60分のまま固定）が正常に動作することを確認。
- 5種テンプレートの完全一致反映、初コメ案内トグル、トークンクリアボタン、およびレートリミットキューの正常動作を確認。
