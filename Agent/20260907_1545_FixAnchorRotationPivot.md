# 作業記録: アンカーポイント指定時の回転動作不具合（軌道ぶれ）の修正

## 1. 目的
- 画像演出機能において、アンカーポイント（「右下」「右上」など）を指定している状態で画像を回転させると、画像が大きく位置ずれして不自然な動き（変な動き）になる不具合を解消する。
- アンカーポイントを中心軸（Pivot）および配置基準点として固定し、アンカーポイントの位置が変わらない自然な回転を実現する。

## 2. 原因の特定
- 以前の実装では、画像を「幾何学的中心（中央）」で回転させた後、回転後の外接矩形（バウンディングボックス：余白を含む領域）の端（例: `w, h`）を基準に `ox = target_x - w, oy = target_y - h` と配置していた。
- 画像を回転させると、外接矩形の幅・高さは角度に応じて大きく変動し、外接矩形の右下隅は「回転後の透明な余白」になってしまう。
- そのため、元のイラストの右下角は外接矩形の右下隅から大きくズレてしまい（最大100px以上のオフセット）、角度を変えるたびに画像全体が斜めや不自然な方向へ大きく吹き飛ぶ軌道を描いていた。

## 3. 修正内容
- **数学的Pivot回転ロジック（`calculate_overlay_placement`）の導入** (`src/utils.py`):
  - 元画像内のアンカーローカル座標 $(A_x, A_y)$ と元画像中心 $(C_x, C_y)$ から相対ベクトル $(dx, dy)$ を算出。
  - 時計回りの角度 $\alpha$ に基づき回転後の相対ベクトル $(dx', dy')$ を算出：
    $$dx' = dx \cos(\alpha) - dy \sin(\alpha)$$
    $$dy' = dx \sin(\alpha) + dy \cos(\alpha)$$
  - 回転後画像内でのアンカー座標を $(\frac{W_{rot}}{2} + dx', \frac{H_{rot}}{2} + dy')$ として正確に逆算。
  - 画面上の目的アンカー座標 $(X, Y)$ に一致するよう貼り付け左上座標 $(P_x, P_y)$ を決定。
- **プレビュー（`app.py`）と動画書き出し（`video.py`）の共通化**:
  - `preprocess_overlay_image` に回転前の拡大縮小サイズ（`scaled_size`）を保持。
  - プレビュー描画・FFmpegレンダリングの双方で `calculate_overlay_placement` を適用。

## 4. 検証結果
- 全9種類のアンカー（重心・左上・上・右上・左・右・左下・下・右下）および0°〜360°の回転角において、アンカー位置のブレ（Drift）が1ピクセル未満（整数丸め誤差のみ）に抑えられ、完璧に固定されて回転することを確認。
