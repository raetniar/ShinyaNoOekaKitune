## 1. きりぬきつーる (`tools/きりぬきつーる/`) 開発・最適化サマリー

### ① Whisperローカル自己学習エンジンの実装 (2026/08/26)
- **概要**: ユーザーが字幕編集を行った際の修正差分（Whisper出力 vs ユーザー確定テキスト）をPC内（`system_files/learned/learned_data.json`）で完全ローカル学習するエンジンを開発。
- **機能**:
  - `vocabulary`: 配信者特有の固有名詞・口癖を自動抽出し、次回のWhisper文字起こし時に `initial_prompt` へ自動注入。
  - `corrections`: 誤字修正ペア（例: 「狐若」➔「初狐羽鹿」）を自動蓄積し、文字起こし完了直後に自動置換。
  - `stats` & 設定画面: 累計学習回数の表示およびワンクリック初期化ボタンを実装。

### ② Gemini 1.5 Flash プロンプト＆バズ分析仕様の高度化 (2026/08/26)
- **5大原則**: 1分完結、冒頭3秒フック、初見文脈自立性、感情ピーク重視、オチ＆ループ性。
- **5軸各20点個別採点 (`score_breakdown`)**:
  - `hook_stop_rate`, `standalone_context`, `emotional_peak`, `follow_through_power`, `loop_timing_quality` の5項目（合計100点）。
- **新項目**: サムネイル最適フレーム時刻（`thumbnail_frame`）、文脈自立性の自己監査根拠（`context_check`）。
- **UI連携**: 切り抜き候補一覧ボタンに `No.1 [98点] (01:15～) タイトル` のスコアバッジを表示。

### ③ メイン画面・ヘッダー・API連携UIの大幅改善 (2026/08/26)
- **Step 1 ヘッダー**: `対象動画:` 直下に `YouTube URL:` 入力欄と `🌐 開く` ボタンを新設し、プロンプト設定タブと双方向リアルタイム同期。
- **Step 1 コピペエリア下部**: `✨ Gemini APIで自動解析` と `📋 コピペから読み込む` を並列配置し、ワンクリック解析を実現。
- **全体設定タブ**: 開いてすぐの画面に `🔑 Google Gemini API Key 設定` 欄を大きく新設。変数 `gemini_api_key_var` による一元管理で入力即時保持・自動保存。
- **不要ボタン整理**: プロンプト設定タブ右下の重複していた解析ボタンを削除し、コピーボタンのみに整理。

### ④ スタンドアロン exe 化 ＆ ディレクトリ整理 (2026/08/26)
- **PyInstaller ビルド**: `CustomTkinter`, `Whisper`, `MoviePy`, `PyTorch` を完全同梱したスタンドアロン exe（約338MB）をビルド。
- **ディレクトリ整頓**: ルート直下は `きりぬきつーる.exe`, `動画/`, `ショート/`, `画像/`, `system_files/` のみに整理。ドキュメント類（PDF, 画像, 仕様書, ガイド）はすべて `system_files/docs/` に集約。
