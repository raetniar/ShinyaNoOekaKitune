# Bot返信文における時間単位の重複（5分分、30秒分等）不具合修正ログ

## 目的
Bot自動返信メッセージ内で、「次回5分分」「あと30秒分」のように「分」が2重になったり「秒分」と誤表示される不具合を修正する。

## 原因分析
- 時間フォーマット関数 `formatDurationString` がすでに `5分` や `30秒` などの単位付き文字列を返しているのに対し、テンプレート文字列（`DEFAULT_TEMPLATES` や設定値）側にも `{required_minutes}分` や `{remain_minutes}分` と固定の「分」が記述されていたため、結合後に「5分分」「30秒分」となってしまっていた。

## 実施した変更
1. `DEFAULT_TEMPLATES` 内の `{remain_minutes}分` および `{required_minutes}分` から直後の「分」を削除。
2. `formatTemplate` 内でテンプレート置換後に `res.replace(/([分秒])\s*分+/g, '$1')` による重複単位の自動除去クリーニング処理を追加。
3. `loadData()` で古い設定（localStorage内）を読み込む際にも `{..._minutes}分` を自動補正する処理を追加。

## 検証結果
- `{required_minutes}` が `5分` や `30秒` や `1分30秒` に展開された際、末尾に余計な「分」が結合されて「5分分」「30秒分」等になる問題が解消され、正しく `次回5分` `次回30秒` と表示されることを確認。

## 対象ファイル
- `tools/裏ガチャシステム/index.html`
