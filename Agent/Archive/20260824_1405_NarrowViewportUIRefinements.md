# 20260824_1405_NarrowViewportUIRefinements.md

## 目的
OBS等の狭小ドック（幅200px〜480px）および通常幅におけるUI・レイアウト崩れ・文字被りの包括的修正とレスポンシブ最適化。

## 対象ツール
- `TwitchManager`（`dev_1.0.3_NarrowViewportUI` ブランチ）

## 変更内容サマリー
1. **IDリストのレイアウト・表示順・余白改善**:
   - カード内の不要な `min-height`（flex-basis 150px 余白バグ）を完全解消。
   - 表示順ツールバー：通常時は `[ 表示順: ] [ 名前順 ▼ ] [ 🔄 重複IDを統合 ]`、狭小時は上段（ラベル＋右上アイコン固定）・下段（プルダウン幅100%）。
   - 名前編集マーク（`[✏]`）：狭小時にカード右上に絶対配置固定。
   - 日付・記念日入力欄：狭小時にカレンダーアイコンを非表示にして入力枠幅を最大化。
2. **コマンド・Twitch時間設定コントロール**:
   - 1セット枠（カプセル枠）を維持したまま、枠内で `[ 0 ]` と `分`（`[ 30 ]` と `秒`）を中央揃えに配置。
3. **その他タブ（バックアップ・復元）**:
   - 狭小幅時に縦1列配置に切り替え、文字やボタンの押しつぶしを防止。
4. **設定モーダル（言語・テーマ・表示設定）**:
   - 言語・テーマボタンのはみ出し防止と自動折り返し対応。
   - 表示設定モーダルの各項目：上段に項目名（テキスト）、下段右端にコンパクトなトグルスイッチ（36x20px）を配置。
5. **レイド設定リンクボタン**:
   - ボタン内テキストの折り返し許可（`white-space: normal`）と文脈に応じた単語区切り（`レイド<wbr>設定<wbr>ページを<wbr>開く`）。
6. **記念日カレンダー（ポップオーバー＆モーダル）**:
   - 通常時は元通りの左右1行レイアウトを維持。
   - 狭小幅時は上段に配信者名（フル幅）、下段に日付・残り日数・バッジを配置し、文字被りゼロを実現。
