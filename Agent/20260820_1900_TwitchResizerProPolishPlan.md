## 1. 実施予定の改善項目（チェックリスト）

### ① テーマ・配色の完全調和（ライト／ダーク両対応）
- [ ] `#preset-selector` などに残っているインラインハードコード（`background: #18181b !important;` 等）を完全撤廃。
- [ ] すべてのデザイン要素を CSS 変数（`--bg-primary`, `--bg-secondary`, `--border-color`, `--text-primary` 等）に統合。
- [ ] ライトモード時にプルダウンやカード枠が不自然に暗く浮かないよう、クリーンな配色に統一。

### ② キャンバス＆コントロールUIの洗練・整理
- [ ] **ドロップゾーン（アップローダー）**:
  - よりすっきりと直感的なドラッグ＆ドロップUIに整形。
- [ ] **プリセット選択**:
  - アイコン付きのモダンなセレクトボックス／ボタングループ化。
- [ ] **ファイル名／スタンプ名入力**:
  - プレフィックス（`ICON_`, `EMOTE_` 等）と入力欄のスマートな一体型デザイン。
- [ ] **スライダー（Range input）＆コントロール**:
  - ズーム・回転・位置調整スライダーのツマミ・バーをモダンなミニマルスタイルに統一。
- [ ] **文字入れ（テキストオーバーレイ）パネル**:
  - フォント選択・縁取り・カラーピッカー・整列ボタンをコンパクトで使いやすいグリッドに整理。

### ③ 実寸チャット＆Twitchプレビューのクオリティ強化
- [ ] **Twitchチャットプレビュー**:
  - 実際のTwitchチャット欄（ダーク／ライト）のUIをより忠実に再現。
  - 実寸エモート（28px/56px/112px）の並びやテキストとの比率をリアルに確認可能にする。
- [ ] **バナー・パネルプレビュー**:
  - 実際の配置時の見え方を直感的に把握できるレイアウト枠の調整。

### ④ 操作フィードバック＆アクションボタン
- [ ] **エクスポート（ダウンロード）ボタン**:
  - 「ZIP一括書き出し」「個別サイズDL」ボタンに視覚的フィードバック（ホバー効果・クリック感）を追加。
- [ ] **レスポンシブ最適化**:
  - タブレット（1024px以下）やスマートフォン（600px以下）でもキャンバスがはみ出さず、スクロール・操作がスムーズに行えるようCSS調整。
