# 20260826_1325_ConfirmAndOptimizePityResetOnAnyWin.md

## 目的
- 天井カウント（`pityCount`）が、天井到達による確定当たり時だけでなく「通常確率による当たり時」にも確実に `0` にリセットされる仕様・挙動の確認およびフォーマット最適化。

## 実装・確認内容
1. **ロジックの確認 (`tools/裏ガチャシステム/index.html`)**:
   - `triggerGachaForListener`:
     - ガチャ実行時に `pullCount`（累計回数）と `pityCount`（天井用カウント）が +1 加算される。
     - **通常当たり（確率判定成功）** または **100連天井確定当たり（`pityCount >= 100`）** のどちらの場合でも、`isWin` が true となり `l.pityCount = 0` へ確実にリセットされる。
     - 累計ガチャ回数（`pullCount`）はリセットされずそのまま通算加算される。
     - 次回配信へも `pityCount` は保持され、当たりが出た瞬間にリセットされる。

2. **表示メッセージの最適化**:
   - ガチャ結果メッセージおよびテンプレート変数（`{required_minutes}` / `{remain_minutes}`）において、秒・分どちらの設定でも正確に表示されるよう `formatDurationString()` で統一。

## 検証結果
- 単体シミュレーションおよびロジック検証にて、通常当たり時・天井当たり時の両方で `pityCount = 0` にリセットされ、ハズレ時のみカウントが進行することを確認完了。
