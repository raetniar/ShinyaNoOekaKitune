# 20260826_1522_OrganizeDirectoryStructure.md

## 目的
- 『きりぬきつーる』のルート直下を整理し、ユーザーが日常的に使う要素のみを配置。ドキュメント類や内部ファイルを `system_files/docs/` へ統合してクリーンな階層を構築。

## 整理後のディレクトリ構成
```
tools/きりぬきつーる/
├── きりぬきつーる.exe          # 【最重要】ダブルクリックで起動する本体exe
├── きりぬきつーる.bat          # Python/uv実行用バックアップバッチ
├── 動画/                       # 元動画（MP4）置き場
├── ショート/                   # 完成した切り抜きショート動画の出力先
├── 画像/                       # キャラクター立ち絵・スタンプ画像置き場
├── system_files/               # 内部システムフォルダ
│   ├── config.json             # 個人設定・APIキー（Git除外）
│   ├── config.example.json     # 公開用初期設定テンプレート
│   ├── docs/                   # ドキュメント・説明書まとめフォルダ
│   │   ├── PDF/images/         # マニュアル用スクリーンショット画像
│   │   ├── 使い方ガイド.html   # HTML形式のマニュアル
│   │   ├── 使い方ガイド.pdf    # PDF形式のマニュアル
│   │   ├── 使い方ガイド.txt    # テキスト形式のマニュアル
│   │   ├── きりぬきつーる_取扱説明書.md
│   │   └── きりぬきつーる_仕様書.md # マスター仕様書
│   ├── learned/                # 自己学習データ保存先
│   ├── src/                    # Pythonソースコード
│   ├── build/                  # ビルド中間生成物（Git除外）
│   └── dist/                   # ビルド出力（Git除外）
└── .gitignore                  # Git除外設定
```

## 実施した変更
1. ルート直下の `PDF/`, `使い方ガイド.*`, `きりぬきつーる_仕様書.md` を `system_files/docs/` に集約。
2. `system_files` 内の旧バックアップ・重複フォルダ（`docs_root`, `src_root`, `run_tool_root.bat`）を安全に削除。
3. `system_files/docs/使い方ガイド.html` 内の画像パスを相対パス（`./PDF/images/...`）に最適化。

## 検証結果
- ルート直下のファイル・フォルダ数が最小限（exe、動画、ショート、画像、bat、system_files、.gitignore のみ）に整理され、極めて見通しが良くなったことを確認。
