# 2026/09/09 13:40 パレット（ドロワー/ポップアップ）への編集モード（画面レイアウト）および画像追加・画像演出の完全復元

## 目的
編集パレット（ドロワー吸着モード / ポップアップ独立モード）の「スタイル設定」タブにおいて、主要字幕文字スタイルのみが表示され、「画面レイアウト（編集モード）」および「画像追加・画像演出（オーバーレイ）」の設定UIが存在しなくなっていた問題を解消する。あわせて、メイン画面の画像演出タブにも手元の画像ファイルを直接選んで追加できる「＋ 追加」ボタンを新設する。

## 課題・原因
1. **パレット内UIの欠落**:
   - レスポンシブ対応時に独立した別ウィンドウとして実装された透過パレット（`setup_palette_styles`）において、文字色・縁取り色・フォントサイズ・プリセットのみが定義されており、メイン画面の `char_panel` にある「画面レイアウト（ブラー背景/黒帯/上下2画面/中央クロップ）」と「画像演出（画像選択/フォルダ/リロード/位置XY/倍率等）」が含まれていなかった。
   - 幅狭画面（コンパクトモード）時やポップアップ化時にメイン画面の `char_panel` が非表示になるため、ユーザーが編集モードの切り替えや画像演出の操作を行えなくなっていた。
2. **ワンクリック画像追加UIの不足**:
   - 画像演出パネルにプリセットドロップダウンとフォルダを開くボタンしかなかったため、エクスプローラーから直接ファイルを選んで追加する「＋ 画像追加」ボタンが求められていた。

## 実施した変更
1. **`app.py`（`setup_palette_styles`）**:
   - **① 画面レイアウト (編集モード)** をパレット最上段に追加:
     - `self.layout_mode_var` とバインドされたドロップダウンメニュー（ブラー背景 / 黒帯 / 上下2画面 / 中央クロップ）を設置。
     - 選択変更時にプレビューへ即時反映。
   - **② 主要字幕スタイル & プリセット**:
     - 文字色・縁取り色・文字サイズ・4種プリセットを2列グリッドでコンパクトに配置。
   - **③ 画像演出 (オーバーレイ)** をパレット下段に追加:
     - プリセット選択プルダウン（`self.p_preset_menu`）
     - **「＋ 画像追加」ボタン**（ファイル選択ダイアログから画像を選択し、自動で「画像」フォルダへコピー＆プリセット登録＆プレビュー反映）
     - フォルダを開くボタン（`📁 画像フォルダを開く`）＆更新ボタン（`🔄 更新`）
     - 位置 X スライダー、位置 Y スライダー、倍率スライダー
     - リセットボタン（`画像の位置・倍率をリセット`）
2. **`add_custom_overlay_image` メソッドの実装**:
   - ファイルダイアログから `.png`, `.jpg`, `.jpeg`, `.webp` を選択し、「画像」ディレクトリへコピー。
   - メイン画面およびパレット側のプリセットメニューを自動更新し、即座に選択・反映。
3. **メイン画面（`setup_char_panel` 内 `tab_img`）の機能強化**:
   - プリセット下段ボタン群に青色の **「＋ 追加」ボタン**（`preset_add_btn`）を新設。
4. **メイン画面 ⇔ パレット間の完全双方向同期**:
   - `on_overlay_x_slider_changed` / `on_overlay_y_slider_changed` / `on_overlay_scale_slider_changed` / `reset_overlay_transform` / `refresh_presets` / `on_preset_selected` において、メイン画面側とパレット側のUIが常に同期するよう連携処理を追加。
5. **スタンドアロンEXE（`きりぬきつーる.exe`）の再ビルド＆配備**:
   - PyInstaller で再ビルド完了、最新EXEを配布ディレクトリへ配置。
