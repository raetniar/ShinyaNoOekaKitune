# 2026/09/09 13:35 字幕クイック編集（パレット）の入力欄横幅・左端位置揃え改修

## 目的
切り抜きツールのプレビュー連動字幕クイック編集（パレット画面）において、タイムコード表示の文字幅が可変だったことにより、テキスト入力欄の左端開始位置および横幅がデコボコになっていた問題を解消し、全行でピシッと一直線に整列させる。

## 課題・原因
1. **タイムコード文字列の桁数変動**:
   - `seconds_to_minsec` が整数秒付近を `00:00`、小数1位を `00:01.5`、小数2位を `00:01.08` と可変桁数で出力していたため、タイムコード文字列全体の文字数が15〜19文字の間で変動していた。
2. **`pack(side="left")` による横幅可変**:
   - タイムコードラベルを `pack(side="left")` で配置していたため、テキスト幅に応じて後続の `txt_entry` の配置開始位置（左端）が毎行ズレていた。

## 実施した変更
1. **`app.py`（`refresh_palette_subtitle_list`）**:
   - **タイムコードのフォーマット固定化**:
     - `fmt_tc` 関数を実装し、すべてのタイムコードを `MM:SS.ss`（常に2桁分:2桁秒.2桁ミリ秒）でフォーマット。
     - タイムコード表示を常に 19 文字（例: `00:00.00 - 00:01.50`）に統一。
   - **Grid レイアウトによる厳密な列幅固定**:
     - `row_f` のレイアウトを `grid` 化。
     - `column 0`: タイムコードラベル（`minsize=150`, `width=145`, `anchor="w"`, `font=("Consolas", 10)`）
     - `column 1`: 字幕入力欄 `txt_entry`（`weight=1`, `sticky="ew"`、全行で左右端が完全に揃う）
     - `column 2`: 削除ボタン（`weight=0`, `sticky="e"`）
2. **スタンドアロンEXE再ビルド＆配備**:
   - `きりぬきつーる.spec` を用いて PyInstaller で再ビルド。
   - `tools/きりぬきつーる/きりぬきつーる.exe` へ最新EXEを配備完了。

## 検証結果
- `python -m py_compile` による構文チェック通過。
- タイムコード文字列生成ロジックの全行19文字完全一致を検証。
- 最新EXEのビルド（Exit Code 0）および配置完了確認。
