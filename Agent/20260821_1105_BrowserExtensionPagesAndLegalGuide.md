## 1. 収益化・法務・規約に関する論点整理（実務・法律家視点）

### (1) どねる（Doneru）等を利用した投げ銭・チップの適法性
- **契約性質**: 民法上の「贈与契約」（無償・善意の応援）。
- **特定商取引法（特商法）の適用**:
  - 拡張機能を「完全無料」で提供し、どねるへのリンクは「開発応援・コーヒー代の奢り」として任意とする場合、売買契約ではないため特商法に基づく「特定商取引法に基づく表記（住所・本名・電話番号の公開）」は原則不要。
  - **NG例**: 「どねるで500円以上支援した人にだけ限定機能の解除キーを渡す」等は役務・デジタルコンテンツの有償提供とみなされ、特商法表記が必要になるリスクや各種ストア規約違反のリスクが発生する。
- **資金決済法・景品表示法**:
  - 寄付型・応援型投げ銭プラットフォーム（どねる、OFUSE、pixiv FANBOX、kofi等）の利用規約に従う限り、個人開発者が直接決済ライセンスを持つ必要はない。

### (2) 対象プラットフォーム（Amazon、Twitch、X等）に関する商標・規約リスク
- **商標権（商標法）・不正競争防止法**:
  - 拡張機能名や紹介ページで「Amazon」「Twitch」「Twitter/X」などの公式商標をロゴごと勝手に使ったり、「公式ツールであるかのような誤認」を与える名称・表記はNG。
  - **推奨策**: 「〇〇 for Amazon」「Twitch向け非公式拡張」といった**説明的使用（記述的商標使用）**にとどめ、「※本ツールは各プラットフォームの公式ツールではありません」という明確な免責条項（Disclaimer）を明記する。
- **プライバシー・ローカル完結**:
  - `AGENTS.md` の技術規約にもある通り、ユーザーのブラウザ内（DOM操作/localStorage）で完結させ、第三者サーバーへのデータ送信を行わない設計にすることで、各サービスのスクレイピング規約やGDPR/個人情報保護法のリスクを最小化する。

### (3) Chrome Web Store (CWS) 開発者規約
- **寄付リンクの設置**: CWSポリシー上、ポップアップやオプション画面に「Buy me a coffee」や「Doneru」等の寄付リンクを配置することは許可されている。
- **プライバシーポリシー**: 単一用途（Single Purpose）と、不要なパーミッション（権限）を要求しないこと、外部送信がない旨の明記。

## 2. ブラウザ拡張ツールの配布方法の比較と推奨戦略

| 配布方法 | メリット | デメリット / 注意点 | 推奨度 |
| :--- | :--- | :--- | :--- |
| **A. Chrome Web Store (公式ストア)** | ・1クリックでインストール可能<br>・自動アップデート対応<br>・安全性の信頼度が高い | ・初回デベロッパー登録料（$5）<br>・Googleによる審査（数日〜1週間）<br>・プライバシーポリシーURL必須 | **大本命（一般ユーザー向け）** |
| **B. Zip配布（デベロッパーモード）** | ・完全無料・審査なし<br>・BOOTHやGitHubで即日配布可能 | ・ユーザーが「デベロッパーモード」をONにして解凍フォルダを読み込む必要がある（導入難易度高）<br>・自動更新されない | **先行配布・テスト版に最適** |
| **C. Firefox Add-ons (AMO)** | ・登録無料・審査比較的早め<br>・Firefoxユーザーへの訴求 | ・Firefox用マニフェスト（Manifest V2/V3の差分対応）が必要 | **サブ配布として有用** |
