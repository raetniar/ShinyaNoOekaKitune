# 20260826_1245_ActiveTimeoutWatcherIdleGuard.md

## 目的
- Twitchパートナー昇格（平均同接100人目標）に向けて、ただ裏画面で放置・寝落ち・離脱しているだけの非アクティブリスナーによる自動ガチャ解放を防止。
- 「意識的に配信を開き、定期的にコメントする本物のアクティブリスナー」だけが視聴時間を蓄積できるようにする**アクティブ判定・放置タイムアウト機能**を実装。

## 実装内容
1. **仕様と判定ロジック**:
   - リスナーが最後にコメントした時刻（`lastActive`）から、設定された**「アクティブ有効期限（デフォルト20分）」**の間だけ実質視聴時間（`activeWatchSeconds`）が加算される。
   - 20分以上コメントがない場合（＝裏画面放置・離脱・寝落ち）、**タイマーの加算が自動的に一時停止（ストップ）**。
   - 再度リスナーが配信でコメントを投稿した瞬間に「アクティブ視聴再開」と判定され、タイマーが再開される。
   - ガチャ実行時、および次回配信リセット時に実質視聴秒数を初期化。

2. **HTML/UI拡張 (`tools/裏ガチャシステム/index.html`)**:
   - セクション1に「アクティブ有効期限 (分 / 放置停止)」入力欄（`#cfgActiveTimeoutMinutes`）を新設（デフォルト20分、0で無制限）。
   - リスナーカード側で、20分以上コメントがなくタイマー停止中のリスナーには `⏸️ 放置停止中` バッジを赤字で表示。

## 検証結果
- ブラウザ実機にて初期値20分のロード、UI入力、カードへの反映、タイマーの安全な蓄積ロジックを確認完了。
