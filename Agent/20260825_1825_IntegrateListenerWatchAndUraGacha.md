# 20260825_1825_IntegrateListenerWatchAndUraGacha

## 目的
`listener_watch.html`（リスナーウォッチ・CRMツール）と `裏ガチャシステム`（滞在時間計測・ROMあぶり出しガチャ）を統合し、Node.jsや事前設定不要で、ブラウザ（またはOBSカスタムブラウザドック）で開くだけで100%完全動作する一体型コックピットツールを構築する。

## 作業内容
1. **Twitch IRC WebSocketチャット接続**:
   - 読み取り専用（匿名）と、チャット自動返信（Bot/本垢/サブ垢認証）の両対応。
2. **🦊。゜◯（ 心の声・吹き出しスタイル ）チャット自動返信**:
   - 初コメ案内: `🦊。゜◯（ @〇〇 さん初コメ記録！【裏ガチャ】タイマースタート！(必要90分/天井まで100回 / !裏ガチャ で確認) ）`
   - 時間不足時: `🦊。゜◯（ @〇〇 さん【裏ガチャまであと35分】(天井まで58回) ）`
   - ハズレ時: `🦊。゜◯（ @〇〇 さん、ハズレ！ (次回75分/天井まで58回) ）`
   - 当たり時: `🎉🦊。゜◯（ @〇〇 さん、【当たり！】おめでとう！✨ 限定イラストURL: ... (次回15分) ）`
3. **🎰 100連天井確定システム（Pity System）**:
   - 100回引いたら100%確定で当たり（SSR）が排出。
   - **引いた回数・天井カウントは次回配信以降も永久に持ち越し・保存**。
4. **設定UIのスマート統合**:
   - 「⚙️ 裏ガチャ＆Bot設定 ▾」ドロワー1つに、ガチャルール・天井回数・Bot返信設定・Nightbotテンプレを整理統合。
5. **ファイル配置・同期**:
   - `パートナー計画/listener_watch.html`
   - `GIT_HTML/tools/裏ガチャシステム/index.html`

## 検証結果
- 吹き出しスタイルメッセージの反映を確認。
