# 20260909_1730_FixNarrowDisplaySettingsAndDefaultAeCsv.md

## 目的
1. **幅狭時の表示設定抜け落ち解消**:
   - ウィンドウ幅を狭めた際（または画面幅 < 1180px の2カラム作業環境時）、右列のスタイル・演出・画面レイアウト設定（`char_panel`）がウィンドウ右外へ押し出されて消え去り、「表示設定がごっそり抜け落ちる」問題を根本解決。
   - 大画面プレビュー（左列）を維持したまま、右側上部に **`[ 📝 字幕リスト ]` ⟷ `[ 🎨 表示設定（レイアウト・文字・演出） ]`** をワンクリックで切り替えられるタブセレクターを新設。
   - 「画面レイアウト（ブラー背景、黒帯、上下2画面、中央クロップ）」、「フォント・サイズ・位置Y・文字色・縁取り」、「画像演出・オーバーレイ」がいつでも快適に設定・プレビュー確認可能に。
2. **Ae用CSV出力 (.csv) のデフォルト☑（ON）化**:
   - 設定読み込み時（`load_settings`）および初期値で、Ae用CSV出力 (.csv) が確実にデフォルトでチェックON（☑）になるように修正。

---

## 実施内容

### 1. 2カラム/幅狭時における表示設定タブ切り替えの実装 (`app.py`)
- **UIコンポーネント新設**:
  - `self.work_tab_box` / `self.work_tab_seg`:
    - `[ 📝 字幕リスト ]`
    - `[ 🎨 表示設定（レイアウト・文字・演出） ]`
  - `time_ctrl` の下部に横幅いっぱいに収容。
- **タブ切り替えハンドラ (`on_work_tab_changed`)**:
  - `🎨 表示設定` 選択時: 字幕リストと下部追加ボタンを非表示化し、`char_panel`（画面レイアウト・文字スタイル・画像演出）を右列に大きく展開。プレビューを見ながらフォントやレイアウトをリアルタイム調整可能。
  - `📝 字幕リスト` 選択時: 字幕編集タイムラインを再表示。
- **レスポンシブ配置ロジックの刷新 (`update_responsive_layout`)**:
  - `width >= 1180px`（ワイド）: 3カラム並列（プレビュー / 字幕 / 表示設定）。タブセレクターは非表示。
  - `720px <= width < 1180px`（ミディアム / 2カラム、作業標準）: 左列にプレビュー（大画面）、右列に再生バー＋作業タブ（字幕 ⟷ 表示設定）。Column 2 を `minsize=0` かつ `grid_forget()` して画面外はみ出しを完全根絶。
  - `width < 720px`（スモール / 1カラム）: 縦積みスタック。

### 2. Ae用CSV出力 (.csv) のデフォルト☑（ON）修正
- `setup_step2_editor`: `self.export_ae_csv_var = ctk.BooleanVar(value=True)`
- `load_settings`: `self.export_ae_csv_var.set(data.get("export_csv", True))`（旧: False だったため保存ファイル読み込み時に外れていた問題を修正）
