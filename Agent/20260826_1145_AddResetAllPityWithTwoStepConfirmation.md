# 20260826_1145_AddResetAllPityWithTwoStepConfirmation.md

## 目的
- 景品入れ替え時などに、全リスナーの天井カウント（回数）を一括で0にリセットできるボタンを新設。
- 誤操作による天井消失を防止するため、2段階の確認ポップアップ（confirm）を実装。

## 実装内容
1. **HTML/UI配置 (`tools/裏ガチャシステム/index.html`)**:
   - 「裏ガチャ＆Bot設定 ▾」内の「裏ガチャ・滞在時間＆天井ルール」セクション下部に、「全員の天井リセット」ボタン（`.btn-sm.danger`）を配置。
   - スタイリッシュなSVGリセットアイコンを付与。

2. **JavaScriptロジック**:
   - **1段階目確認**: `【確認 1/2】全員の天井カウントを一括で「0回」にリセットしますか？（※景品の入れ替え時などに実行します。コメント数やメモ・Pin・累計ガチャ回数はそのまま保持されます）`
   - **2段階目確認**: `【最終確認 2/2】本当に実行してよろしいですか？※全リスナーの天井カウントが即座に0回へ初期化され、元に戻すことはできません。`
   - 2段階とも承認された場合のみ、全リスナーの `pityCount = 0` にリセットし、`saveData()` と `render()` で即時反映。

## 検証結果
- ブラウザ実機にて配置・スタイリングおよび2段階確認ダイアログの挙動を確認完了。
