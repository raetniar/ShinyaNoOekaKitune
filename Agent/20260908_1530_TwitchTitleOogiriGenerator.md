# 20260908_1530_TwitchTitleOogiriGenerator.md

## 目的
Twitch配信における「深夜お絵描き作業枠」等の無味乾燥な予定調和タイトルを永久封印し、yunelugi式の急成長ドライバーである「自虐・情緒・大喜利・感情爆発・指示厨ホイホイ構文」を初狐羽鹿の世界観（アトリエ×ポンコツ×AIようか）に落とし込んだ専用Webツール『Twitch大喜利タイトルジェネレーター』を新規構築する。
カテゴリ、今日の気分、食べたもの、今日の予定（マイルストーン）を入力することで、クリック率（CTR）を最大化する大喜利タイトルをワンクリックで同時生成・コピー可能とする。

## 作業予定 / 実装方針
1. **新規ツール作成**:
   - `tools/TwitchTitleGenerator/index.html`
   - 初狐羽鹿専用ダークテーマ（`--bg: #0b0e14`, `--card-bg: #151b23`, `--accent: #84cc16`, `--twitch-purple: #9146ff`）
   - 純粋なインラインSVGアイコン（絵文字フォント非依存）
   - カテゴリ切替（お絵描き・アトリエ、逆転裁判・推理、ホラゲ・パニック、登りゲー・高難度、深夜雑談・作業BGM）
   - 3大入力項目（気分、食べたもの、予定・目標）＋クイック入力タグチップ
   - 5大切り口タイトル同時生成ロジック（自虐限界型、指示厨教え魔型、AIようか罵倒型、情緒深夜ポエム型、2.5hタイムアタック型）
   - Twitchスマホアプリで切れない「先頭30文字ハイライト」機能
   - ワンクリックコピー＆トースト通知
2. **相互連携**:
   - `tools/TwitterPostGenerator/index.html` に相互ナビゲーションリンクを追加し、Twitchタイトル決定からX告知文生成へのシームレスな移行を実現。
