# 20260901_1640_PetSettingsAndHeaderRefinement.md

## 目的
ペット設定タブ（`tab-settings`）およびトップヘッダーのUI/UXをリファクタリングし、ユーザー指示のレイアウト調整・数値入力化・Spine 2Dモデル一括投入対応・知識辞書と語彙録のセット化・ヘッダーメニューへのJSON保存/読込移動を漏れなく実装する。

## 作業内容
1. **トップヘッダーの最適化**:
   - 最下部にあった「記憶・語彙データバックアップ (JSON保存/読込)」ボタンをトップヘッダー右上（メニューバー領域）へ移設。
   - すっきりとしたコンパクトなアクションボタンとして常時アクセス可能に配置。

2. **ペット設定タブの上部レイアウト調整**:
   - **横並び 50%:50%**: Twitchチャンネル名とペット（相棒）の名前を横並び 50%:50% に配置。
   - **VOICEVOX設定**:
     - 「再接続」「声のテスト再生」ボタンを見出し右上にコンパクトに移動。
     - 読み上げ音量（%）およびピッチ調整の表示欄を直接入力可能な `<input type="number">` ボックス化し、スライダーと双方向同期（`js/tts.js`）。

3. **アバター設定（Spine 2D対応・レギュレーションフリー ＆ PNGTuber 4列横並び化）**:
   - 「🎨 PNGTuber (4表情)」と「🦴 Spine 2D」の切り替えタブUIを新設。
   - PNGTuber設定の4表情スロット（1.待機、2.発話、3.目閉じ、4.笑顔）を縦積みから均等な**4列横並びグリッド（`repeat(4, 1fr)`）**へと最適化。
   - `js/spine-avatar.js` の `setAvatarMode` における `display: grid` 保持処理を修正し、`css/style.css` にも補強スタイルを追加。
   - Spineファイル一括投入エリア（ドラッグ＆ドロップ対応、解像度・サイズ制限なし）を設置。
   - `js/spine-avatar.js` に `setAvatarMode` および `handleSpineBulkUpload` を実装し、Spine Web Playerとの連携基盤を整備。
   - `js/petAI.js` と `js/youka.js` のグローバル変数（`isAutoTalkActive` 等）の二重定義を `var` に安全化。

4. **Spine 2D マルチトラック合成（レイヤリング）＆ エディター風コントローラー**:
   - **Track 0 (常時待機/Idle)**: ベースアニメーションを常時ループ再生。
   - **Track 1 (まばたき/Blink)**: 2.5〜5.5秒のランダム間隔で自動割り込み合成（オートブリンク）。
   - **Track 2 (発話/Talk)**: TTS音声読み上げ・AIトーク中に口パクをリアルタイム合成。
   - **Track 3 (感情/Happy)**: 笑顔・喜びステート時に表情アニメーションを合成。
   - **Spineエディター風トラックコントローラーUI**:
     - Track 0〜3の各ドロップダウンからモデル内のアニメーション名を動的に選択・変更可能。
     - 各トラックごとの「▶ テスト」再生ボタン、全体再生速度（1.0x）調整機能を搭載。
   - **Spine 4.3 最新ランタイム対応 ＆ 安全フォールバック**:
     - `@esotericsoftware/spine-player@4.3.*` を採用し、Spine 4.3で書き出した `.skel` バイナリに対応。
     - エラー発生時は自動的に PNGTuber 立ち絵へ安全フォールバックし、OBSオーバーレイでも真っ黒にならない仕様を実装。

5. **知識辞書 ＆ 語彙録のセット化**:
   - 「あなたの脳内知識辞書」と「ペットのAI生成語彙録（Gemini名言アーカイブ）」を1つのカードコンテナにセットとしてまとめ、4番の位置に集約。

6. **Spine 2D「あいうえお Talk Slider（フレームタイム固定）」＆ 母音リップシンク完全自動化**:
   - `face/mouth_A...` 等の個別クリップ方式に加え、1つの `talk` アニメーション（コンストレイント連動）に `0F:無言, 1F:あ, 2F:い, 3F:う, 4F:え, 5F:お` を割り当てた「Talk Slider方式」を完全サポート。
   - `(frame + 0.5) / 30` による境界タイムシークと、`animationState.apply(skeleton); skeleton.updateWorldTransform();` による強制即時適用ロジックを実装し、1F以外の各母音への切り替わりを確実に反映。
   - 発話終了時は `0.000s (0F: 無言/口閉じ)` に自動復帰。

7. **パートナー運用フォルダ（http://127.0.0.1:3456/）への完全同期**:
   - `GIT_HTML/tools/StreamTalkAssistant_shigu/` ↔ `【02_UikoUka_活動】/パートナー計画/StreamTalkAssistant/` 間の `index.html`, `overlay.html`, `css/style.css`, 各種JSファイルおよび `spine/` フォルダを完全同期。
