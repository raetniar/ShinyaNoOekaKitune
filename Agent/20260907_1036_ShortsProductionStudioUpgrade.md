## 1. 目的

13. **作業読込時のプレビュー自動復元＆スタイル設定見切れ解消**:

    - **根本原因の解明**:
      - **プレビュー消失**: `update_responsive_layout` の `wide` モード配置処理において、古いコード（プレビューと字幕を `row=3` に配置）が残っていたため、ウィンドウリサイズ時にプレビューと字幕が画面外（下部）へ追いやられ、シークバーだけが画面に残っていた。また、`load_project` で内部の動画パス変数 `self.input_video_path` への代入が漏れていた。
      - **パーツ見切れ**: 右側スタイルパネル（`char_panel`）内で「画面レイアウト」「フォント」等のプルダウンが固定幅（150px, 170px）で横並び配置されていたこと、および `rf` の各カラムの最小幅（260 + 400 + 300 = 960px）が広すぎたため、ウィンドウ幅 800px〜950px 前後で右端が画面外へ突き抜けて見切れていた。
    - **対策**:
      - **プレビュー・字幕の縦貫通レイアウト完全同期**: `update_responsive_layout` の `wide` モードを修正し、プレビューを左列（row 1〜3）縦貫通、字幕エディタを中央列（row 2）、キュー追加ボタンを中央列（row 3）に正確に配置。
      - **スタイルパネルの見切れ根絶**: 「画面レイアウト」「フォント」プルダウンを縦積み＆横幅100%（`fill="x"`）に刷新。カラム最小幅も `210 + 260 + 240` に最適化し、幅 800px や 920px でも文字やメニューが絶対に切れない構造へ改修。
      - **読込時のプレビュー即時描画**: `load_project` 内で `self.input_video_path` を確実に設定し、読み込み完了直後に `self.after(50, self.show_current_frame)` を実行。プロジェクト読込と同時に動画プレビュー画面がパッと即座に立ち上がるよう改善。
    - **検証**:
      - `test_step2_layout.py` で幅 1200px, 920px, 800px を検証。`layout_menu` や `font_menu` の右端が見切れず、プレビューも縦貫通（高さ547〜577px）で安定表示されることを数値確認。
    - **スタンドアロン exe 再ビルド & デプロイ**:
      - PyInstaller ビルド完了後、`tools/きりぬきつーる/きりぬきつーる.exe` へ最新バイナリを自動反映。
