# 20260909_1320_KirinukiHeaderCollapsible.md

## 1. 目的
- ユーザー様からのご要望：
  > **「ここを閉じられるようにしたい。2、3に切り替えたときは自動的に閉じる」**
- 対象：
  - 『きりぬきつーる』（`tools/きりぬきつーる`）のメイン画面上部ヘッダー（案件/クライアント、対象動画、YouTube URL、作業保存/読込、グレースケールスイッチ、プレイリスト操作領域）。
- 目的：
  - 「② 字幕・編集」および「③ 書き出し・ログ」作業時に、画面上部のヘッダー領域を自動的に折りたたんで作業画面（プレビュー、字幕タイムライン等）の表示領域を縦方向に大幅拡大。
  - ヘッダー開閉トグルボタン（▼ / ▶）を設置し、ユーザーが必要に応じて手動でもいつでも自由に開閉（折りたたみ/展開）できるようにする。

---

## 2. 実装方針と設計詳細

### ① ヘッダー開閉トグルボタン（▼）の配置
- ユーザー提示のUI指示（オレンジの三角マーク位置）に基づき、案件ラベルの左端に控えめでスタイリッシュなトグルボタン `self.header_toggle_btn`（▼）を設置。
- 展開時は「▼」をクリックすることで、ヘッダー全体を即座にスリムバーへと収納可能。

### ② 折りたたみ時用サマリーバー（`header_collapsed_bar`）の導入
- ヘッダー折りたたみ時は、高さ28pxのスリムな1行バーを表示：
  - **展開ボタン**: `[ ▶ 案件・動画設定を展開 ]`
  - **サマリーテキスト**: 現在選択中の案件プロファイル名および対象動画ファイル名を控えめに表示（`案件: ○○ | 動画: ○○`）。閉じた状態でも作業対象が一目で把握可能。
  - **「作業保存」クイックボタン**: 編集・書き出し作業中にヘッダーを閉じたままでもワンクリックでプロジェクト保存（JSON）が可能。
- ウィンドウ幅リサイズ（responsive wide/narrow）時にも折りたたみ状態を確実に維持。

### ③ ウィザードステップ連動（自動折りたたみ＆展開）
- `switch_wizard_step(step)` にて：
  - **「① 切り抜き候補」**: ヘッダーを自動展開（動画選択やプロンプト設定を行うステップのため）。
  - **「② 字幕・編集」**: ヘッダーを**自動的に閉じる**（プレビューと字幕タイムラインの視認性を最大化）。
  - **「③ 書き出し・ログ」**: ヘッダーを**自動的に閉じる**（キュー一覧と進捗ログの表示領域を最大化）。
- ②や③のステップにいても、トグルボタン（`▶ 案件・動画設定を展開`）を押すことでいつでも手動で開いて動画パスの確認や設定変更が可能。

1. **`tools/きりぬきつーる/system_files/src/app.py`**:

     - `self.header_collapsed` が `True` の場合、全入力コントロールを `grid_forget()` し、`header_collapsed_bar` のみを表示する分岐を追加。

   - 連動トリガー追加:
     - `switch_wizard_step`: step1 で `set_header_collapsed(False)`、step2/step3 で `set_header_collapsed(True)`。
     - `select_video` / `on_client_profile_selected`: サマリーテキスト自動更新。
