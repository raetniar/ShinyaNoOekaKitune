# 20260826_1135_FixClearOAuthDuplicateAndManualGacha.md

## 目的
- 「クリア」ボタン（`clearOAuthBtn`）のイベントリスナー二重登録バグの解消・1本化。
- 配信者によるカード上「ガチャ実行」ボタンの手動実行時（`isManual === true`）に、視聴時間条件をバイパスして即時ガチャ抽選を可能にする仕様改善。

## 実装内容
1. **イベントリスナー二重登録の解消 (`tools/裏ガチャシステム/index.html`)**:
   - 2箇所に分散していた `clearOAuthBtn` の `click` イベントを1箇所に統合。
   - 確認ダイアログ（`confirm`）で「消去後は読取のみモードでチャット受信を継続します」と案内し、OK時にトークンを消去して安全に匿名接続へ再接続（`connectTwitch()`）するよう整理。

2. **配信者による手動ガチャ実行の仕様明確化**:
   - `triggerGachaForListener(l, isManual = false)` 内の時間不足判定を `if(!isManual && elapsed < required)` に更新。
   - 視聴者のチャットコマンド実行時は通常通り視聴時間を厳格判定し、配信者が手動でカードの「ガチャ実行」ボタンを押した際は時間制限に関わらず即座にガチャを引けるボーナス/特別実行機能として有効化。

## 検証結果
- JavaScript構文エラーなし。
- 重複リスナーが完全に解消され、手動ガチャ実行の挙動が正常化されたことを確認。
