# 初狐羽鹿 総合HUB

## 目的
ツール集を維持し、V活動・イラスト・配信・制作を案内するトップページを作る。

## 作業予定 / 実装方針
- 既存index.htmlをtools.htmlに完全コピーして従来の入口を保存。
- index.htmlとassets/hub.css、assets/hub.jsで軽量な静的HUBを実装。追加ライブラリなし。
- HOME / LIVE / WORKS / CONTENTS / TOOLS / LINKS。確認できない作品・配信予定・動画は作らない。
- リポジトリ内の画像を使用。黒猫モチーフなし。
- Commit / Push / 公開操作は実施しない。
