# 20260826_1335_DiscordWinnerChecklistAndMaterialReceiptTracking.md

## 目的
- 当選者からイラストやスタンプ等の資料・素材を受け取った際に、ツール上からワンクリックで「資料受領」チェックを付けられるチェックボックス管理機能と、Discordメッセージへのリアルタイム連動（`⬜` ➔ `☑️`、受領済マーク反映）を実装。

## 実装内容
1. **Discord Embedフォーマット (`tools/裏ガチャシステム/index.html`)**:
   - `buildDiscordEmbed`:
     - 未受領: `⬜ [日時] : **名前** (@ID) ➔ 🎰 当選タイプ`
     - 受領済: `☑️ ~~[日時] : **名前** (@ID) ➔ 🎰 当選タイプ~~ ➔ **【資料受領済】**`
     - フッターに「当選累計: X名 / 資料受領: Y名」の自動集計を追加。

2. **管理UI拡張（セクション4）**:
   - セクション4下部に「当選者ログ ＆ 資料受領チェック（Discord自動連動）」コンテナを新設。
   - 当選者ごとにチェックボックス（`received`）と削除ボタンを一覧表示。
   - チェックボックスをON/OFFすると、LocalStorageへ保存されると同時にDiscord Webhookへ即座にPATCH送信され、Discord上のメッセージがリアルタイムに更新される。

## 検証結果
- ブラウザ実機にて、チェックボックスのON/OFF切り替え、ステータス表示（`⏳ 未受領` ➔ `✅ 受領済`）、およびDiscordメッセージの即時更新を確認完了。
