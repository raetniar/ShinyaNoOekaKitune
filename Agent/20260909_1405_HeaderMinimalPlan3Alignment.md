# 2026/09/09 14:05 ヘッダー領域のミニマル・統合型改修（案3：ボタン半減＆全行の縦横ライン・高さ28px完全統一）

## 目的
メイン画面上部の案件・動画・YouTube設定ヘッダーにおいて、ボタン数が多く配置が凸凹（階段状）になっていたガチャガチャ感を解消し、縦横のラインと高さ（28px）をピシッと揃え、ボタン数を半減させる（案3）。

## 課題・原因
1. **多すぎるボタンと散らばった配置**:
   - `[新規]`, `[削除]`, `[作業保存]`, `[作業読込]`, `[グレースケール]`, `[参照...]`, `[📋 リスト]`, `[📂 フォルダ]`, `[💾 URL保存]` と9個ものボタン・スイッチが混在。
   - 1行目右（300px）、2行目右（230px）、3行目右（90px）と右側ボタングループの横幅がバラバラで、縦の境界線が階段状にズレていた。
2. **手動保存の手間**:
   - YouTube URLを入力した後にわざわざ「💾 URL保存」ボタンを押す必要があった。

## 実施した変更
1. **ボタンの削減＆統合（9個 ➔ 4個＋1スイッチへ集約）**:
   - **案件操作の統合**:
     - メイン画面の「新規」「削除」ボタンを撤去。
     - 案件プルダウン（`client_profile_menu`）の選択肢末尾に「＋ 新規案件を作成...」「🗑 現在の案件を削除...」を統合。メニューからワンタップで作成・削除ダイアログを起動。
   - **YouTube URLの完全自動保存化**:
     - 「💾 URL保存」ボタンを撤去。
     - URL入力欄（`youtube_entry_hdr`）の `<FocusOut>`（フォーカス移動時）および `<Return>`（Enterキー押下時）に `save_sidecar_url()` を自動実行。
   - **動画ファイル操作の集約**:
     - `[動画 参照...]` と `[📂 フォルダ]` の2つに集約。
2. **グリッドの完全整列＆縦幅・高さ28px統一**:
   - **列0（ラベル固定列: 120px）**:
     - `案件/クライアント:`, `対象動画:`, `YouTube:` の左端・右端が1pxの狂いもなく完全縦揃い。
   - **列1（入力エリア: 伸縮100%）**:
     - 案件プルダウン、動画パス入力欄、YouTube URL入力欄の開始X位置・終了X位置が全行で完全に一致。高さも `height=28` で統一。
   - **列2（操作ボタングループ固定列: 180px固定）**:
     - 行0: `[💾 作業保存]` (88px) ＋ `[📂 作業読込]` (88px)
     - 行1: `[動画 参照...]` (88px) ＋ `[📂 フォルダ]` (88px)
     - 行2: `[グレースケール]` スイッチ (180px幅フレーム内に右寄せ配置)
     - すべての行で右側ブロックの横幅が `180px` で完全一致し、凸凹・隙間が完全に解消。
3. **スタンドアロンEXE再ビルド＆配備**:
   - PyInstaller で再ビルド完了、最新の `tools/きりぬきつーる/きりぬきつーる.exe` を配備。
