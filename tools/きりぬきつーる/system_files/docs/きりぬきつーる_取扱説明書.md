# 🦊 AI搭載ショート動画切り抜きツール『きりぬきつーる』取扱説明書

本ツールは、長尺の配信動画や実況動画から、**Gemini (AI)** と **Whisper (音声認識)** を組み合わせて「バズるショート動画（縦型）」を半自動で切り出し、自動字幕をつけて書き出すことができる高機能編集ツールです。

---

## 📂 フォルダ構成

本ツールを展開すると、以下のフォルダ構成になっています。

*   `きりぬきつーる.exe` : ツール起動用プログラム（本体）
*   `動画/` : 切り抜き元となる元の動画ファイルを置くフォルダ
*   `ショート/` : 完成したショート動画（縦型）や字幕ファイルが保存される出力先フォルダ
*   `画像/` : 画像オーバーレイ機能で使用する画像を置くフォルダ
*   `system_files/` : 内部動作用のプログラム、依存アセット、フォント設定等

---

## 🛠️ 基本的な使い方（全体の流れ）

### STEP 1：パーソナルデータ（配信者情報）の設定
1. ツールを起動し、**「パーソナルデータ設定」** タブを開きます。
2. 以下の項目を詳しく入力します（これらを元にAIがバズる編集プランを練ります）。
   *   **配信者様の主なキャラクターや特徴**
   *   **主な視聴者層**
   *   **動画のジャンルや概要**
   *   **現在の登録者数・主な投稿プラットフォーム・過去実績** など
3. **「パーソナルデータを保存」** ボタンをクリックします。

### STEP 2：Gemini用プロンプトの作成とAI分析
1. **「Geminiプロンプト設定」** タブを開きます。
2. **「対象 of YouTube動画リンク」** に、切り抜きたい配信アーカイブのURLを入力します。
3. 切り抜き候補の **「目標個数」**（例：5個、10個など）を入力します。
4. **「📋 プロンプトをコピー」** ボタンをクリックします（STEP 1のパーソナルデータが自動埋め込みされます）。
5. **「🌐 Geminiを開く」** をクリックし、ブラウザで開いたGoogle Geminiのチャット欄にコピーしたプロンプトをそのまま貼り付けて送信します。

> [!TIP]
> Geminiが動画データを元に、タイムスタンプ、バズるタイトル、動画構成、オチの付け方、テロップ指示を含んだ編集プランを作成してくれます。

### STEP 3：切り抜き候補の読み込み
1. Geminiの出力テキスト（マークダウン形式）をまるごとコピーします。
2. ツールの **「切り抜き＆字幕編集（一括）」** タブを開きます。
3. 画面左側の手順ナビから **「① 切り抜き候補」** ボタンを選択します。
4. 画面上部の「対象動画」の **「参照...」** から、ローカルにある切り抜き元の動画ファイルを選択します。
5. **「【1. Gemini出力コピペエリア】」** に、コピーしたGeminiの出力をそのまま貼り付けます。
6. **「コピペから候補を読み込む」** ボタンをクリックします。
7. 右側の **「【2. 切り抜き候補一覧】」** に、自動解析された切り抜き候補リストが表示されます。

### STEP 4：Whisperによる自動音声認識（字幕生成）
1. 「① 切り抜き候補」画面の候補一覧から、字幕をつけたい項目にチェックを入れます（複数選択可）。
2. **「🪄 選択した候補の字幕を生成」** ボタンをクリックします。
3. ローカルのAI（Whisper）が動画の該当箇所の音声を読み込み、高精度な文字起こしを自動で行います。

> [!NOTE]
> 固有名詞や配信者特有の用語が誤認識される場合は、メインタブの **「全体設定」** 内の **「文字起こし辞書」** メニューに事前に正しい文字と読みを登録しておくと、音声認識の精度が劇的に向上します。

### STEP 5：字幕・スタイルの微調整とキュー追加
1. 左側の手順ナビから **「② 字幕・編集」** ボタンを選択します。
2. 候補一覧から選択してロードされたシーンが中央のプレビューエリアに表示されます。
3. プレビュー下のタイムラインや字幕テキストエリアで、開始・終了時間や、字幕テキスト・タイミングを秒単位で手動微調整できます。
4. 右側の**スタイル設定**（文字・段落、画像オーバーレイ）パネルで以下を設定できます：
   *   **フォント・サイズ・文字色・太字・斜体**
   *   **フチ取り（境界線）の色と太さ**、**影の深さと透明度**
   *   **配置（位置）**
   *   **Loud Zoom（音量連動ズーム）**：話し声の音量に合わせて画面や字幕がダイナミックにズームし、テンポ感を生みます。
   *   **画像オーバーレイ**：位置X, Yや倍率、回転、不透明度、アンカーポイント（重心、左上、右上、左下、右下）をスライダー等で細かく調整できます。
5. 調整が終わったら、**「➕ 編集した内容で処理キューに追加する」** ボタンをクリックしてレンダリング待ちリストに登録します。

### STEP 6：一括書き出し
1. 左側の手順ナビから **「③ 書き出し・ログ」** ボタンを選択します。
2. 処理キューリストが左側に表示され、右側に書き出しオプションと実行ボタンが配置されています。
3. **「🎬 登録されたすべてのキューを一括切り抜き実行 (開始)」** をクリックします。
4. 進捗ログが右下にリアルタイム表示され、しばらく待つと `ショート/` フォルダに完成した動画が書き出されます。

## 🎨 高度な書き出しオプション
動画出力時、以下のチェックボックスを有効にすることで用途に応じた出力が可能です：
*   **SRT出力**：動画ファイルとは別に、YouTube等に直接アップロードできる字幕字幕ファイル（.srt）を書き出します。
*   **AE CSV出力**：Adobe Premiere Pro や After Effects などのプロ用編集ソフトへ字幕データを直接インポートするためのCSVファイルを書き出します。
*   **字幕の焼き付けなし**：字幕テロップの入っていない、映像の切り出しのみのクリーンな動画を出力します（外部の動画編集ソフトでイチからテロップを作る際に便利です）。

## 💡 トラブルシューティング

### ❓ 字幕生成時に「No such file or directory: ... mel_filters.npz」と表示されてエラーになる
*   **原因**：音声認識AI（Whisper）に必要なモデルの動作アセットファイルが実行ファイルに同梱されていませんでした。
*   **対策**：バージョン `2026-07-17` 以降の最新の `きりぬきつーる.exe`（または最新の `セットアップ.exe` から再インストールしたもの）では、このアセットが完全に内包されるよう修正されています。新しいプログラムを実行してください。

### ❓ 動作が重い・動画の書き出しに時間がかかる
*   書き出し処理（レンダリング）はPCのCPU/GPU性能を大きく消費します。処理中は他の重いアプリケーションや配信ソフトを閉じることを推奨します。
*   「グレースケール」スイッチが有効になっていると、動画が白黒になりプレビュー負荷が下がります。
