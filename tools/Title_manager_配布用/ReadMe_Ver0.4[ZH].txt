1. Ver0.4 主要新功能与更新
------------------------------------------------------------
■ 完全本地化支持
- 单个文件现在支持日语、英语和中文。本工具会自动检测您的浏览器语言，并自动切换所有文本（包括 UI、工具提示和警报）。

■ 日期自动替换功能 ({date})
- 如果在标题中包含“{date}”，在同步到 Twitch（PUSH）时，它将被自动替换为今天的日期。
- 您可以在设置菜单中选择日期显示格式（如 MM/DD、YYYY/MM/DD）。
- 顶部栏新增“● {date}”按钮，方便您快速复制替换字符串。

■ 自定义工具提示
- 所有按钮现在在悬停时都会显示说明性的工具提示。
- 指令选项卡中的各项功能（如 /shoutout、/clear 等）的作用现在一目了然。

■ UI 设计与稳定性提升
- 新增了实时时钟、自定义设计的对话框（警报），并优化了配色方案，以提升在 OBS 中的可视性和易用性。

------------------------------------------------------------
2. 安全的安装方法（※为了防止因 OBS 机制导致的错误）
------------------------------------------------------------
如果直接在 OBS 停靠栏中进行初始设置，可能会导致 Twitch 的登录界面无法正常打开。
请务必按照以下步骤进行安装：

① 将下载的“Title_manager_localize_Ver0.4.html”文件保存在电脑中不会被移动的位置。

② 双击文件，使用 Google Chrome 等常用浏览器打开。

③ 点击右上角的“⚙（设置）”按钮，进行初始设置（Broadcaster ID、Client ID、Token 等）。
   *有关设置步骤，请参考工具内的“❔（说明）”按钮。

④ 设置完成后，从顶部的“Backup（备份）”标签页复制数据，并暂时保存在记事本等工具中。

⑤ 打开 OBS 菜单的 [停靠部件(Docks)] ＞ [自定义浏览器停靠部件(Custom Browser Docks)]。
   将第②步中浏览器地址栏的路径（例如：file:///C:/Users/...）粘贴到 URL 栏并应用。

⑥ 当工具在 OBS 中显示后，打开“Backup（备份）”标签页，粘贴第④步的数据以恢复设置。

------------------------------------------------------------
3. 关于安全与备份（重要）
------------------------------------------------------------
■ 关于安全
- 请绝对不要将您的“Client ID”或“Token”告诉他人。
- 请注意不要让“设置界面”出现在直播画面中。

■ 关于数据保存
- 数据保存在浏览器的缓存（Local Storage）中。为防止数据丢失，请定期从“Backup（备份）”标签页复制数据并保存到文本文件中。
