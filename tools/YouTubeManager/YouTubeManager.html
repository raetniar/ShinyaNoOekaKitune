Google OAuth 2.0 認証トークンを設定することで、YouTube Data API v3 経由で直接配信枠の作成や更新を行えます。詳しい手順は上記のヘルプから確認できます。
❓ YouTube認証 (OAuth 2.0 Playground) 接続ガイド

YouTubeマネージャーで枠作成・タイトル更新を行うには、YouTube Data API v3 のアクセス許可（OAuth 2.0 アクセストークン）が必要です。

1時間制限と長期（半永久）利用について:
Access Token 単体の有効期限は Google の仕様上 1時間 (3,600秒) です。
OAuth 2.0 Playground で一緒に発行される Refresh Token（リフレッシュトークン） も設定画面に入力しておくと、期限切れのたびにアプリが裏で自動再発行を行い、何ヶ月も半永久的に自動でログイン状態を維持できます！

※OAuth 2.0 Playground は英語表記ですが、操作するのは画面左側のみです。

【トークン発行の3ステップ (画面左側)】

Step 1: 権限(Scope)の選択
  1. OAuth 2.0 Playground ↗ を別タブで開きます。
  2. 画面左側リストから YouTube Data API v3 をクリックして開きます。
  3. リスト内の https://www.googleapis.com/auth/youtube にチェックを入れます。
    (※一番下の「Input your own scopes」欄に直接貼り付けてもOKです)
  4. 青いボタン [Authorize APIs] をクリックします。
Step 2: Googleアカウントでログイン・承認
  1. 配信で使用する YouTube チャンネルの Google アカウントを選択します。
  2. アクセスリクエスト画面で [続行] または [許可] をクリックします。
Step 3: トークンの発行とコピー
  1. 自動的に Playground 画面の Step 2 に戻ります。
  2. 青いボタン [Exchange authorization code for tokens] をクリックします。
  3. 画面左下に表示される以下の2つをコピーします：
    • Access token: ya29.a0AR... (短期1時間キー)
    • Refresh token: 1//0... (長期自動更新キー)
  4. YouTubeマネージャーの ⚙️ 設定 を開き、それぞれの欄に貼り付けて [保存] を押せば完了です！
🔒 安全上の注意: アクセストークン・リフレッシュトークンはあなた個人の配信管理権限を持つ秘密鍵です。配信画面やSNS、公開掲示板等に絶対に掲載しないでください。
