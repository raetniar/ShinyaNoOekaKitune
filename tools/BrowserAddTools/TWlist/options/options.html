🔑 Twitch API 設定（任意・推奨）

※ 未設定でも公開API（クイックモード）で自動動作しますが、Twitch Developer APIキーを設定するとより高速・安定して配信情報を取得できます。

APIキーの取得手順（無料・2分）
  1. Twitch Developer Console にTwitchアカウントでログイン。
  2. 「アプリケーションを登録」をクリック。
  3. 名前: TWlist-MyNotif（自由） / OAuthリダイレクトURL: http://localhost / カテゴリ: Application Integration を選択して「作成」。
  4. 一覧から作成したアプリの「管理」を開き、「クライアントID」をコピーして上記に貼り付け。
  5. 「新しいシークレット」を押して生成されたシークレットをコピーして上記に貼り付け。
