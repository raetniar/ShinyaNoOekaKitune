# TW-Alert - 配信開始通知＆リスト（Twitch対応・非公式）

登録したTwitch配信者が配信を開始したときに、デスクトップ通知を自動送信するブラウザ拡張機能（Manifest V3）です。
拡張機能のポップアップを開くことで、現在配信中のチャンネルを一覧で確認できます。
※本ツールは個人開発の非公式・サードパーティ製ツールです。

---

## 🌟 主な機能

- 🔔 **配信開始の自動通知**: Twitchを開いていなくても、登録チャンネルが配信開始したらデスクトップ通知を送信。クリックすると配信ページへ直行。
- 🎮 **配信中リスト一覧**: ポップアップから現在配信中のチャンネル（タイトル、ゲームカテゴリ、視聴者数、経過時間）をひと目で確認。
- 🔗 **簡単URL登録**: TwitchのURL（`https://twitch.tv/チャンネル名`）またはユーザー名を貼り付けるだけでワンクリック登録。
- 🔢 **リアルタイム人数バッジ**: 拡張機能アイコン上に現在LIVE配信中の人数を表示。
- 💾 **バックアップ・復元**: 登録チャンネルリストのJSONエクスポート/インポート、テキスト一括登録に対応。

---

## 🚀 導入手順（Chrome / Edge / Brave / Vivaldi）

1. **ブラウザの拡張機能管理ページを開く**
   - Google Chrome: `chrome://extensions/` をアドレスバーに入力
   - Microsoft Edge: `edge://extensions/` をアドレスバーに入力
2. **「デベロッパーモード」を有効化**
   - 画面右上（または左下）にある「デベロッパーモード」のスイッチをONにします。
3. **拡張機能を読み込む**
   - 「**パッケージ化されていない拡張機能を読み込む**」ボタンをクリックします。
   - フォルダ選択画面で、本フォルダ（`TWlist`）を選択します。
4. **完了！**
   - ツールバーに紫色の「TWlist」アイコンが表示されます（ピン留めしておくと便利です）。

---

## 📖 使い方

1. **チャンネルの登録**
   - 拡張機能アイコンをクリックしてポップアップを開きます。
   - 上部の入力欄に、追加したい配信者のURL（例: `https://www.twitch.tv/shroud`）またはチャンネル名を入力して「追加」を押します。
2. **配信の視聴**
   - 配信が始まるとデスクトップ通知が届きます。通知をクリックすると新しいタブで配信が開きます。
   - ポップアップを開いて、配信中リストのカードをクリックしても配信ページが開きます。
3. **設定の変更**
   - ポップアップ右上の歯車アイコンをクリックすると設定画面が開きます。
   - チェック間隔（1分〜10分）や通知のON/OFF、登録リストのバックアップが行えます。
